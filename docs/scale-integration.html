Hardware integration guide Connecting a Mettler-Toledo Ariva-S-Mini (1070) checkout scale to the TARE pack-station tablet.

Ariva Scale → TARE Tablet

The short version

  1. Power the scale from its own 12 V wall adapter (it is not USB-powered).
  2. Run the scale's RJ50→USB cable (#72256236) into a USB-C OTG hub, then into the tablet's USB-C port.
  3. On the scale, set Comm Type = USB Virtual COM and Protocol = 8217 Mettler-Toledo.
  4. In the app, Settings → Weight source → Serial (Streaming) and match the serial values.
  5. Place a weight — it flows into the shared scale reading and every order checks live.

Data path is a single serial link: the scale streams weight frames up the USB cable; Android's USB-host stack presents it to the app as a serial device. No PC and no cloud sit in the middle.

Configuration — both sides must match
Step 1 · on the scale

Scale soft-switch setup (Group 3)

Enter setup: hold the >T< (Tare) button ~5 s until CONF shows. Zero = confirm / next, Tare = step through groups. Open Group 3 and set:

StepSettingChoose
3.1Communication Type1 — USB Ser/CDC (Virtual COM)  (use 0 — RS-232 only for the DB9/FTDI route)
3.2Baud rate3 — 9600
3.3Parity0 — None
3.4Data bits1 — 8 data bit
3.5Stop bits1 — 1 stop bit
3.6Protocol Selection3 — 8217 Mettler-Toledo (WO)

Step out to EXIT → SAVE to store and reboot. The scale is ready when the weight display returns.

Step 2 · in the TARE app

App settings (Settings → Weight source)

  • Set Weight source to Serial — Streaming (8217 WO streams continuously). If no reading appears, switch to Serial — Polling, which requests each reading with W⏎.
  • Under Serial connection, match the scale exactly: 9600 / None / 8 / 1, protocol name 8217 Mettler-Toledo.
  • Plug in the scale — Android shows a one-time "Allow access to USB device?" prompt. Tick always and accept.
  • The reading flows into the shared ON SCALE value; every order compares live, exactly as in test mode.

Auto-connect  The app opens the port on launch and also when the scale is plugged in later — no manual "connect" step.

Reference · protocol & drivers

Protocol, units & the driver page

  • Protocol 8217 Mettler-Toledo (WO). "Weights-Only": the scale reports the live weight; the host can also send zero/tare commands. The app reads the weight frames and updates the shared reading.
  • Units. The Ariva is metric and reports kilograms (e.g. 0.250). The app converts to grams automatically (a decimal value ⇒ kg ⇒ ×1000; a bare integer ⇒ grams; kg/g/lb tokens are also honoured).
  • The Ariva "Drivers" download page (JPOS / OPOS / Virtual COM Ports) is for PC POS systems (Windows/Linux). You do not need any of those for the Android tablet — the app talks to the FTDI/CDC device directly. Only install the Virtual-COM (FTDI) driver if you later connect the scale to a Windows PC.
If something's off

Troubleshooting

SymptomFix
No reading / "connect a scale"Confirm the scale is on (wall adapter), the OTG hub works, and you accepted the USB permission prompt. Re-check that the scale's Comm Type matches the cable (USB-CDC for #72256236). Try Serial — Polling if streaming shows nothing.
Weight is ~1000× offUnit mismatch. The app assumes kg for decimal values; if your scale is set to output integer grams it's already handled. If still wrong, tell us the raw frame (below).
Garbled / no framesBaud/parity/data/stop bits must match on both sides. Start with 9600 / None / 8 / 1; if garbled, try the classic MT set 9600 / Even / 7 / 1 on both.
Tablet won't chargeUse the USB-C PD hub and feed its PD-C input from the charger; a plain OTG adapter can't charge and host at once.
Reading raw framesThe driver logs each raw frame via adb logcat — useful for tuning if a non-standard framing appears.

Safety  Always unplug power before connecting/disconnecting cabling. Use only genuine Mettler-Toledo cables — counterfeit assemblies can damage the scale and void warranty.
